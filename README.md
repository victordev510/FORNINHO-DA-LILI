# FORNINHO-DA-LILI

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um site para uma confeitaria, com o objetivo de apresentar seus produtos, destacar suas especialidades e proporcionar uma experiência agradável e intuitiva aos clientes.

O site possui um design moderno, atrativo e responsivo, valorizando a identidade visual da confeitaria e facilitando a navegação dos usuários.

## 🎯 Objetivos

- Apresentar os produtos disponíveis na confeitaria.
- Exibir imagens e descrições dos bolos e doces.
- Destacar promoções e produtos especiais.
- Facilitar o contato entre clientes e a confeitaria.
- Proporcionar uma navegação simples e intuitiva.

## 💻 Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e identidade visual.

## ✨ Funcionalidades

- Página inicial com apresentação da confeitaria.
- Catálogo de bolos, doces e sobremesas.
- Seção de produtos em destaque.
- Galeria de imagens.
- Informações sobre a confeitaria.
- Área de contato para os clientes.

## 🎨 Design e interface

O projeto busca transmitir uma identidade visual delicada e sofisticada, utilizando elementos gráficos relacionados ao universo da confeitaria, imagens atrativas e uma organização visual que valoriza os produtos.
